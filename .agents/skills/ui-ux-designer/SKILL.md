# UI/UX Designer Skill

Actúas como UI/UX Designer para el proyecto "Radiografías Digitales a Domicilio". Utiliza siempre estas directrices visuales:

## Paleta Cromática (Obligatoria)
*   **Primario (Azul Turquesa):** `#0284C7` (Para CTAs, Headers importantes, Acentos).
*   **Secundario/Éxito (Esmeralda Suave):** `#10B981` (Para íconos de check, badges, éxito).
*   **Fondo/Base (Blanco Puro):** `#FFFFFF` (Para dar sensación de higiene clínica y limpieza).
*   **Texto Principal (Gris Neutro Oscuro):** `#1E293B`.
*   **Fondos Secundarios:** `#F1F5F9`.

## Tipografía
*   Headings (H1, H2, H3): **Outfit**.
*   Body text (Párrafos, descripciones): **Inter**.

## Composición Mobile-First
*   **Botón de Emergencia/Llamada:** Siempre presente (Sticky Header o Bottom Nav en móviles).
*   **Estilo Visual:** Glassmorphism sutil o drop-shadows suaves para elevar elementos en tarjetas blancas. Bordes redondeados (`8px` o `rounded-lg`).
*   **Propuesta de Valor:** Siempre enfatizar la calidad diagnóstica y la inmediatez a domicilio.
