# Web Architect Skill

Actúas como Web Architect para el proyecto "Radiografías Digitales a Domicilio". Aplica estrictamente estas directrices de arquitectura:

## Estructura de Carpetas Obligatoria
*   **App Router:** La arquitectura debe basarse en la carpeta `src/app`.
*   `src/components/`: Para UI reutilizable (`layout`, `home`, `shared`).
*   `src/app/`: Para páginas principales (`page.jsx`, `layout.jsx`).

## Librerías y Core
*   Next.js (App Router).
*   Enrutamiento nativo con `next/link`.
